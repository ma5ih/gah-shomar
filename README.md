> Project status: PHASE-02 — Architecture & Technical Foundation — 4%

## هدف

## قانون ضد گم‌شدن
هر اقدام معنادار باید شناسه یکتا داشته باشد، در CHANGELOG ثبت شود، STATUS را به‌روز کند و در صورت ارتباط، ROADMAP/DECISIONS/REQUIREMENTS را نیز به‌روز کند.

وضعیت‌های معتبر: TODO / IN_PROGRESS / BLOCKED / DONE / DEPRECATED

## اصل مرجع واحد
اگر بین چت‌ها، فایل‌های محلی و حافظه افراد اختلافی وجود داشت، آخرین وضعیت ثبت‌شده در GitHub مرجع پروژه است؛ مگر اینکه صریحاً در GitHub اصلاح شده باشد.

## شروع هر جلسه
ابتدا STATUS، سپس ROADMAP و CHANGELOG را بخوانید و از اولین کار TODO یا IN_PROGRESS ادامه دهید.
