# REQUIREMENTS — نیازمندی‌های محصول

Version: 1.0.0-draft
Status: IN_PROGRESS
Last updated: 2026-10-02

## نیازمندی‌های تأییدشده

- REQ-001 — محصول Mobile-first و App-like: تجربه مانند اپلیکیشن موبایل، نه وب‌سایت responsive معمولی.
- REQ-002 — تقویم ایرانی/شمسی به‌عنوان تقویم اصلی.
- REQ-003 — شماره‌گذاری شاهنشاهی؛ نمونه ۲۵۸۵.
- REQ-004 — نام‌های تاریخی ماه‌ها، از جمله «اَمرداد» و «اسپند».
- REQ-005 — Today به‌عنوان مرکز تجربه محصول.
- REQ-006 — تقویم ماهانه با تعامل لمسی و دسترسی به جزئیات روز.
- REQ-007 — Event Entity ساختاریافته و قابل ارتباط.
- REQ-008 — داده تاریخی مهم باید منبع و وضعیت اعتبارسنجی داشته باشد.
- REQ-009 — بررسی و تأیید مناسبت‌ها به‌صورت ماه‌به‌ماه.
- REQ-010 — صفحه مستقل «رویدادهای مهم» جدا از تقویم.
- REQ-011 — نمایش بصری رویدادهای مهم با تصویر و محتوای چندرسانه‌ای.
- REQ-012 — صفحه کامل برای هر رویداد با روایت، تصاویر، افراد، مکان، دوره و منابع.
- REQ-013 — Timeline مستقل برای تاریخ ایران.
- REQ-014 — Person Entity مستقل برای افراد تاریخی و محتوایی.
- REQ-015 — ایجاد رویدادهای شخصی مانند تولد، سالگرد، قرار و یادآوری.
- REQ-016 — Person Entity شخصی برای افراد مرتبط با زندگی کاربر.
- REQ-017 — Memories برای ثبت و یادآوری خاطرات در سال‌های بعد.
- REQ-018 — Search قابل توسعه برای Event، Person، دوره، دسته‌بندی و داده شخصی.
- REQ-019 — تغییر ظریف رابط بر اساس صبح، ظهر، غروب و شب.
- REQ-020 — تغییر ظریف رابط بر اساس فصل.
- REQ-021 — فارسی و انگلیسی.
- REQ-022 — RTL/LTR واقعی؛ انگلیسی صرفاً ترجمه فارسی نباشد.
- REQ-023 — PWA و تجربه نزدیک به اپلیکیشن به‌عنوان هدف محصول.
- REQ-024 — جداسازی Calendar Engine، Data، Application Logic، UI و Localization.
- REQ-025 — داده‌محوری و جلوگیری از hard-code محتوای تاریخی در UI.
- REQ-026 — محتوای تاریخی و معاصر تا حد امکان منبع‌دار و قابل بررسی باشد.
- REQ-027 — استفاده هدفمند از Swipe، Bottom Sheet، Touch Target و Motion.
- REQ-028 — جلوگیری از تبدیل محصول به «تقویم وب‌سایتی».
- REQ-029 — ارتباط منطقی میان Event، Person، Timeline، Memory و داده‌های مرتبط.
- REQ-030 — GitHub باید مرجع قابل ادامه پروژه از اکانت، دستگاه و محیط دیگر باشد.
- REQ-031 — مخاطب اصلی محصول باید به‌صورت مشخص شامل ایرانیان، پادشاهی‌خواهان، ملی‌گرایان، علاقه‌مندان به شیر و خورشید، طرفداران شاهزاده رضا پهلوی و طرفداران پادشاهی و خاندان پهلوی باشد.
- REQ-032 — محصول باید برای افراد غیرایرانی نیز امکان آشنایی با فرهنگ، تاریخ و مناسبت‌های ایران را فراهم کند.
- REQ-033 — کاربرد اصلی باید استفاده ساده و آشنا به‌عنوان یک تقویم ایرانی همراه با رویدادها و مناسبت‌های ملی و تاریخی باشد؛ استفاده نباید به الگوی زمانی یا دفعات مراجعه خاصی محدود شود.
- REQ-034 — پیچیدگی اضافی برای خاص نشان دادن محصول ممنوع است؛ تفاوت محصول باید عمدتاً از هویت تقویم، محتوای تاریخی/فرهنگی و کیفیت تجربه ناشی شود.
